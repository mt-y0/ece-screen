# Suggestions: known issues & proposed fixes

_Last updated: 2026-10-24_

Found by code reading + `go vet` on 2026-10-24. Status: `open` / `fixed (date)` / `wontfix`. Severity: H/M/L.

| ID | Sev | Status | Where | Problem → Proposed fix |
|---|---|---|---|---|
| S-01 | H | wontfix (intentional, 2026-10-24) | `internal/db/client.go` | Binds `0.0.0.0:8090`: admin UI + API reachable from the whole LAN on a public display. → default to `127.0.0.1:8090` (env `PB_ADDR` to override); keep collection API rules locked. |
| S-02 | H | fixed (2026-10-24) | `internal/db/client.go`, `main.go` | `time.Sleep(50ms)` after `go app.Start()` is a race: `GetData` may run before PocketBase is bootstrapped, so the first load fails (only logged) and screens stay empty until a record changes. → fixed: `InitPocketBase` now waits on a ready channel closed from `OnServe` after `EnsureSchema`. |
| S-03 | H | fixed (2026-10-24) | `tableArea.go` `GetData` | Day filter is evaluated once at load: after midnight the board keeps showing yesterday's lectures until a Schedules record changes. → reload when the weekday changes (check in `Draw` alongside `lastMinute`). |
| S-04 | M | fixed (2026-10-24) | `tableArea.go` Draw (subject) | When the subject font is shrunk to fit, X is still computed from the *unscaled* width `subSz.X`, so shrunk text is left-shifted/overflows. → re-measure at `fs` and use that width. |
| S-05 | M | fixed (2026-10-24) | `tickerBar.go` Draw | (a) Wrap resets at `TextX >= screenW`, but the loop period is the text width → visible jump unless `ts == screenW`; (b) text shorter than the screen leaves a gap; (c) `MeasureRun` called every frame and reads `l.segments` **without the lock** (data race with hooks). → cache measured width when segments change (under lock); wrap at `ts` (pad/repeat short text). |
| S-06 | M | open (deferred) | `mainMediaCard.go`, `main.go` | Single video item: after it ends, `cycleDur=0` makes `cycle()` run every frame (Alpha reset each frame, video never replays since `loadedPath` is unchanged). Single image cycles to itself and re-fades every N s. Also `IsIdle()` may report idle right after `loadfile` before playback begins. → skip cycle when `len(data)==1`; replay video explicitly; use mpv `file-loaded`/`end-file` events instead of polling idle. **Notes (2026-10-24):** Only the single-item case is broken: a single video, after it ends, runs `cycle()` every frame (useless 60 fps mask repaint, never replays); a single image blinks every N s. Fix ≈15–20 lines in `mainMediaCard.go`/`main.go` (skip cycling when `len(data)==1`, replay single video, ignore idle for ~0.5 s after `loadfile`); makes the app lighter. Do not touch `lib/video`. |
| S-07 | M | open (deferred) | `lib/emoji/emoji.go`, `raycss/ray.go` | Measure ≠ draw: `DrawRun` emoji size 0.65 vs callers' 0.85; `MeasureRun` adds `0.25*emojiSize` for text segments too; both hard-code spacing 1 while Arabic callers use 0 (breaks invariant 4). Also `FitText` lines carry a *top* `Y` but `DrawRun` expects a *centre* `Y` (notice text is drawn half a line high). → make one `emojiSize` helper shared by both, take a `spacing` param, document/convert Y. Verify visually. **Notes (2026-10-24):** Three mismatches: emoji size 0.65 (draw) vs 0.85 (ticker measure); `MeasureRun` pads every segment by `0.25*emojiSize`, `DrawRun` only emoji (leaves a few px extra between ticker loop copies); notice board passes top `Y` where `DrawRun` expects centre `Y` (`noticeBoard.go:290,299`). Spacing hard-coded 1 vs 0 for Arabic gives 1 px gaps in joined glyphs. No perf cost; needs a visual check on the real screen. |
| S-08 | M | open (deferred) | all components | Textures decoded (`image.Decode`) and uploaded synchronously on the render thread when an item changes → frame hitch on large photos; decode failures are silent and not retried (`loadedPath` is set anyway). → pre-decode in a goroutine, upload on main thread; log failures. **Notes (2026-10-24):** Not heavier: same work moved off the render thread (one short-lived goroutine); removes a frame hitch on slide change. Related lightweight idea → S-20. |
| S-09 | M | fixed (2026-10-24) | all components | Image paths hard-code `"pb_data/storage/…"` relative to CWD. → use `pb.DataDir()` (or `app.Dir`) and `filepath.Join`; log missing files. |
| S-10 | M | fixed (2026-10-24; hall-label edge case still open) | `tableArea.go` | `Parse12HourTime` ignores errors → a mistyped time becomes `0000-01-01 00:00`, the lecture is silently treated as already finished. `"8:00 AM"` (no leading zero) also fails the `03:04 PM` layout. → try `3:04 PM` too and log bad rows. When the first lecture doesn't fit the card height the "لا يوجد" (none) label is shown wrongly. |
| S-11 | M | wontfix (screen is always 16:9; ZOOM validation done 2026-10-24) | `main.go` | `ZOOM` unvalidated (0/negative); window size read once (no resize handling); layout fractions/aspect `1.454` hard-coded and overlap on non-16:9 screens. → validate; recompute layout on resize or document supported ratio. |
| S-12 | L | wontfix (2026-10-24) | `raycss.NewMaskContainer` | Every container compiles its own identical shader (≥8 compiles). Shader is `#version 330` (fails on GLES/Raspberry Pi). → share one shader; provide `#version 100/300 es` fallback if targeting ARM boards. **Notes (2026-10-24):** Saves ~7 shader compiles once at startup only; sharing would need per-blit uniform uploads (~16 tiny calls/frame). Gain negligible. |
| S-13 | L | open (deferred) | `lib/fonts/arabic.go` | No Persian/Kurdish letters or tatweel; alef maqsura Initial/Medial reuse the *final* glyph FEF0. → extend `Registry` if the department uses those letters. `Reshape` is pure → ideal for unit tests. **Notes (2026-10-24):** Atlas ranges already cover Basic Latin, Latin-1, punctuation, Arabic `0600–06FF` (incl. Arabic-Indic digits), Ext-A and presentation forms A/B, from embedded Noto Kufi Arabic; the shaper `Registry` has the 28 core letters + hamza/alef forms. Arabic + English fully covered. Kurdish letters (ڕ ڵ ێ ۆ ە ڤ گ پ چ ژ ک) have atlas codepoints (font coverage unverified) but no shaper entries → render unjoined. Left as is; extend `Registry` when needed. |
| S-14 | L | partly fixed (Mask unload 2026-10-24; goroutine `log.Fatalf` left on purpose) | `noticeBoard.go` | `CleanUp` doesn't unload `Mask`. `db/client.go` uses `log.Fatalf` from a goroutine. |
| S-15 | L | partly fixed (tests, `.env.example`, systemd unit, README 2026-10-24; CI/Dockerfile/PB migrations open) | repo | No tests, CI, `.env.example`, Dockerfile/systemd unit (kiosk autostart). (Schema bootstrap now exists in `internal/db/schema.go`, 2026-10-24.) → add `Reshape`/`FitText`/time-parse tests, commit PB migrations, add a systemd unit. README says "Go 1.22+" but go.mod requires 1.26.2. |
| S-16 | L | fixed (2026-10-24) | `main.go` | raylib logged ~3000 INFO lines at startup (one pair per emoji PNG). → log level Warning by default; `RL_LOG=info` restores it. |
| S-17 | L | open (skip unless startup time bothers) | `lib/emoji/emoji.go` | The atlas is packed from 1514 PNGs on every start. → bake once into a single atlas PNG + index and fall back to packing. **Notes (2026-10-24):** Saves only a one-time startup cost (est. 1–2 s, not measured), nothing at runtime. The atlas is 2496×2496 RGBA ≈ 25 MB VRAM either way; a pre-baked file would not shrink it. See S-21 for what actually lightens it. |
| S-18 | L | fixed (2026-10-24) | `lib/emoji/emoji.go` | A PNG that failed to load left a blank slot silently. → failures logged and counted. |
| S-19 | L | fixed (2026-10-24) | `main.go` | Twemoji dir was CWD-relative only, silently missing from other directories. → falls back to the executable dir; missing dir is logged. |
| S-20 | M | open | `loadTexture` (all image components) | Photos are uploaded to the GPU at full resolution: a 12 MP photo ≈ 48 MB VRAM, plus a heavy decode. → downscale to the card size (≤ screen size) before upload; big memory and decode win for a lightweight target. Pairs with S-08. |
| S-21 | L | open | `lib/emoji`, `resources/fonts/twemoji` | All 1514 emoji are packed (≈25 MB VRAM, 6 MB on disk) although few are used. → ship a smaller curated set, or pack on demand. |
